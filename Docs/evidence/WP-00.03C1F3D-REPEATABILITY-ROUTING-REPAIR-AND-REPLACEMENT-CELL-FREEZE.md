# WP-00.03C1F3D — Repeatability routing repair and replacement cell freeze

## Scope and safety outcome

C1F3D is an offline control-plane and evidence-routing repair. No provider was contacted, no inference occurred, no API credential was inspected, and no database, broker, or trading mutation was enabled. The consumed r2 cell was not rerun and its response semantics were not inspected.

## r2 failure proof

The repeatability profile already selected the frozen C1F/v6 provider request contract through `usesC1F3SemanticStack` and `diagnosticInitialRequest`. After the mocked provider returned a response, however, both diagnostic analysis and evidence projection classified profiles with `isC1F3Profile`, which recognized only the original C1F3 Generalization and Boundary identities. The r2 profile therefore fell through to the historical C1E/v5 projection route, whose prompt guard rejected the v6 prompt identity.

The pre-fix offline regression `TestC1F3RepeatabilityR2ExecutionPersistsC1FProjectionOffline` reproduced the exact post-provider failure after one mocked response:

```text
diagnostic evidence projection route: v5 output contract requires prompt "ai-shadow-prompt-v5-causal-attribution"
```

No HTTP transport was used. The failing test used a HIGH-confidence `UNRESOLVED` response that is valid under C1F and invalid under the historical v5 validator.

## Routing repair

`diagnosticExecutionContractForProfile` now provides a single explicit, version-aware classification for historical v4, historical C1E/v5, original C1F/C1F3, consumed C1F repeatability r2, and replacement C1F repeatability r3. The classification binds the expected prompt, output schema, validator, policy, and scorer identities. Preparation, provider construction, response parsing, and persisted evidence projection all consume this classification; unknown profiles and mismatched contracts fail before provider construction.

Historical C1E/v5 remains on its historical route. Original C1F3 and both repeatability identities use `ParseValidateAndApplyC1F`. Authorization remains family-specific: original C1F3, consumed r2, and replacement r3 cannot cross-authorize one another.

The post-fix regression executes the actual r2 profile through all 48 cases with a mock provider and persists non-null raw model output, typed attribution, causal-attribution policy, effective semantic mapping, and deterministic resolution. The separate command-level r3 mock executes the same 48-case route without HTTP and produces an immutable synthetic artifact index.
