# WP-03.01 — Market price/OHLCV provider hardening

## A. Package/result

Implemented one existing read-only market path: Financial Datasets historical prices. The path now routes through the accepted Phase 02 provider registry, operational executor, exact raw-payload persistence, batch normalization, canonical Observation V2, provenance, and provider-neutral `CanonicalMarketBar` projection.

The official Financial Datasets contract is bounded to historical EOD intervals (day/week/month/year) with ticker, dates, OHLCV fields, and a provider `time` value; it does not document adjustment or regular/extended-session semantics. The implementation therefore supports documented daily EOD only and represents adjustment/timezone/session as explicit unknown/unspecified values. See the [historical prices API documentation](https://docs.financialdatasets.ai/api/prices/historical).

## H–Q. Contract and ownership

- Provider identity: `pvd_financial_datasets` (`financialdatasets.api`); logical source: `src_financial_datasets_historical_prices`; capability: `market.bars`.
- Logical source and transport/provider identity remain distinct. Canonical contracts contain no vendor DTOs.
- The provider adapter owns request construction, strict schema parsing, bounded capture, and deterministic mapping. `libs/contracts/provider` owns registry, operational, raw, normalization, freshness, health, and qualification contracts.
- Instrument identity is resolved through canonical `Instrument` external IDs (`financialdatasets.ticker`/`ticker.us`); ticker strings are never canonical identities.
- OHLCV semantics: daily EOD bar, provider date labels normalized to UTC midnight start and next-day UTC interval end; market timezone/session and adjusted/unadjusted state are explicit `UNKNOWN`/`PROVIDER_EOD_SESSION_UNSPECIFIED`; no regular/extended-session or corporate-action inference is performed. OHLC invariants, finite positive prices, non-negative integer volume, ordering, duplicates, completed intervals, and strict date syntax are validated.
- Exact entity-body bytes are captured before JSON decoding, persisted with `PersistRawPayload`, digest-verified, and passed to the normalizer by immutable `RawPayloadRef`. No headers, credentials, or payload bodies are logged.
- Normalizer routing is by provider identity + `market.bars` + versioned raw schema (`financialdatasets.prices.historical/documented-2026-08-26/v1`) + Observation V2 target. Mapping component: `cmp_financial_datasets_daily_bars` v1.0.0 with content identity.
- Every accepted Observation retains canonical instrument, source, provider/capability through raw evidence, raw payload ID/digest, normalizer/provenance, observed and collected timestamps, and canonical schema/revision.
- Freshness is deliberately caller-owned and separate from acquisition/health. Production TTL is not invented; deterministic tests use a bounded policy. Raw receipt time cannot make an old EOD observation fresh.
- Operational retries, rate limits, typed failures, and health use Phase 02 `OperationalExecutor`; no second retry stack and no stale fallback were added. Qualification remains independent and `NOT_ASSESSED` without evidence-backed governance data.

## R–U. Replaceability, storage, live verification, artifact

`BatchNormalizer`/`BatchNormalizationResult` extend the accepted Phase 02 pipeline so one provider response can deterministically yield five canonical observations per bar without leaking provider DTOs. `ProjectCanonicalMarketBars` consumes only canonical observations, so another provider/raw schema can map to the same research-facing semantics. A second real provider was not integrated.

Existing Redis market cache and legacy market-data tables remain feature-local/cache/legacy; they are not treated as forensic raw identity. The accepted in-memory raw store is used for deterministic proof. No database migration or new persistence backend was required.

Live verification is credential-gated: approved Jax environment variables contained no Financial Datasets key at execution time. No network call, signup, purchase, or secret was attempted. Consequently there is no real-evidence artifact; the deterministic artifact below records exact fixture identity only.
