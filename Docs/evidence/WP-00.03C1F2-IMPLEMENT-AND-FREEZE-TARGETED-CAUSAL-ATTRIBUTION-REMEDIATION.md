## Prompt v6

Prompt v6 keeps the exact v5 JSON schema and adds general boundaries only:

- retain the safest issuer identity supported by the event; do not invent legal suffixes, parents, subsidiaries, divisions, ownership, or tickers;
- separate semantic issuer recognition from deterministic asset support;
- distinguish companies/legal issuers from bounded market, sector, commodity, index, and macro exposures;
- reject nearest-enum, keyword, affiliation, commentary, secondary-effect, and speculative-beneficiary proxy fallbacks;
- require a proxy to be the uniquely principal bounded exposure when no eligible direct principal issuer exists;
- operationalize PRINCIPAL, EQUAL_PRINCIPAL, SECONDARY_AFFECTED, CONTEXT_ONLY, and POSSIBLE_PRINCIPAL without changing the enum;
- retain every issuer needed to express causality instead of manufacturing a singleton principal.

The corrective prompt now treats validator errors as structural constraints rather than new evidence. It explicitly prohibits inventing or substituting an issuer, legal entity, parent, ticker, proxy, participant, fact, or relationship. When typed evidence required for DIRECT or PROXY is missing, it directs preservation of uncertainty in a valid UNRESOLVED state. The retry limit remains one corrective attempt.

## Semantic issuer identity

`ai-shadow-issuer-semantic-identity-v1` returns `EXACT`, `EQUIVALENT`, `DISTINCT`, or `AMBIGUOUS` and never resolves an asset. Its deterministic rules are:

1. mechanically normalize case, surrounding whitespace, punctuation, and `&`/`and` in the same manner as the trusted resolver;
2. use existing explicit resolver canonical entities and aliases as the controlled identity catalog;
3. permit mechanically safe trailing legal-form differences (`Inc.`, `Incorporated`, `Corporation`, `Corp.`, `Company`, `Co.`, `Limited`, `Ltd.`, `plc`, `AG`, `N.V.`, `S.A.`, `A/S`) when the resulting identity key is collision-free;
4. return AMBIGUOUS, and therefore no scoring match, when a surface or legal-form key maps to multiple semantic issuers;
5. return DISTINCT when there is no exact form, explicit one-issuer alias, or collision-free legal-format equivalence.

There is no Levenshtein distance, token threshold, substring match, embedding, inference, or other fuzzy comparison. Parent/subsidiary, brand/parent, division/company, product/company, and same-name entities are not collapsed unless an existing explicit approved alias defines the identity. The comparator emits no symbol and cannot turn an unsupported issuer into a supported asset.

## Validator and retry result

The C1F validator duplicates the accepted v5 structural contract except for one removed condition: UNRESOLVED no longer requires LOW `mapping_confidence`. HIGH, MEDIUM, and LOW are valid when the causal state otherwise requires abstention. PRINCIPAL and EQUAL_PRINCIPAL cardinality, issuer uniqueness, DIRECT and PROXY projections, role/proxy exclusion, bounded exposure vocabulary, selected-mapping consistency, and contradictory-state rejection remain unchanged.
