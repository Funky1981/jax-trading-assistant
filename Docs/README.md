# Jax Documentation Index

This index defines the documentation authority chain. Historical and imported
material is retained for traceability but cannot authorize current work.

## Authority hierarchy

1. `Docs/JAX_PRODUCT_CHARTER.md` — product truth.
2. `Docs/ROADMAP.md` — roadmap and sequencing truth.
3. `Docs/STATUS.md` — current status truth.
4. `Docs/CAPABILITY_MATRIX.md` — capability and evidence-maturity truth.
5. `Docs/BUILD/CURRENT_PACKAGE.md` — current build routing.
6. `Docs/ARCHITECTURE.md` — accepted runtime architecture.
7. Relevant domain documents.

`AGENTS.md` governs repository execution and safety workflow. It does not
replace product or roadmap truth.
