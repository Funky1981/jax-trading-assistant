# Promotion Rules

Allowed states:

```text
IDEA
HYPOTHESIS
BACKTESTED_WEAK
BACKTESTED_PROMISING
PAPER_READY
PAPER_REJECTED
EXPLORATORY_PAPER_OBSERVED
FORMAL_FORWARD_PAPER_EVIDENCE
```

Exploratory observations do not demonstrate an edge. Formal forward-paper
evidence requires separate authorization and review. Live-ready is not part of
the current roadmap.
