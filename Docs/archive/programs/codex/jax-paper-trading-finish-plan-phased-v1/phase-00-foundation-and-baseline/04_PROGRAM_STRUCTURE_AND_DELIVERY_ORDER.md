# Program Structure and Delivery Order

## Delivery principle
Do not implement this as random feature work.
Implement it in **strict order** because several missing pieces block trust.

## Workstreams
1. Safety and truth path
2. Data and strategy model
3. Always-on candidate generation
4. Approval and paper execution
5. Operator pages
6. Assistant and AI audit
7. Trust gates and sign-off

## Mandatory order
1. Phase 0: truth-path hardening
2. Phase 1: data / strategy model completion
3. Phase 2: always-on watcher + candidates
4. Phase 3: approval queue + execution instructions
5. Phase 4: operator pages
6. Phase 5: assistant + AI audit
7. Phase 6: trust gates + paper readiness sign-off

Do not build the assistant before the approval and operator workflows exist.
Do not trust paper trading before provenance and replay gates exist.
