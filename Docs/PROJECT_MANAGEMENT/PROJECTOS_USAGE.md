# ProjectOS Usage

ProjectOS files under this directory support planning mechanics: backlog, decisions, risks, releases, issue templates, and board setup. They are not current product or build-routing authority.

When maintaining a project record:

- link current direction to `Docs/ROADMAP.md`;
- link implementation routing to `Docs/BUILD/CURRENT_PACKAGE.md`;
- record uncertainty rather than inventing a phase or authorization;
- preserve `NO_TRADE`, human approval, and the exploratory/formal evidence firewall.

The generic `project/roadmap.md` and `project/current-focus.md` files are retained as compatibility pointers only.
