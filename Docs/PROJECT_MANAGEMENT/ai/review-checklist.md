# Review Checklist

Use this before considering work done.

## Roadmap / Scope

- [ ] Work links to roadmap
- [ ] Work links to backlog item
- [ ] No unrelated scope added
- [ ] Acceptance criteria met

## Code Quality

- [ ] Code is readable
- [ ] Boundaries are clear
- [ ] No unnecessary dependencies
- [ ] No hidden assumptions
- [ ] Error handling is reasonable
- [ ] Logging is reasonable where needed

## Tests / Validation

- [ ] Unit tests added/updated where appropriate
- [ ] Integration checks considered
- [ ] Manual verification documented
- [ ] Existing tests still pass, or failures are explained

## Security / Data

- [ ] No secrets committed
- [ ] Inputs validated where needed
- [ ] Data access is controlled
- [ ] Sensitive data handling considered

## Operations

- [ ] Configuration documented
- [ ] Failure modes considered
- [ ] Observability considered
- [ ] Deployment impact considered

## ProjectOS Updates

- [ ] Backlog updated
- [ ] Current focus updated
- [ ] Decision log updated if needed
- [ ] Risk log updated if needed
- [ ] Release log updated if needed
