# Command: Update Project State

Update ProjectOS files after meaningful work.

## Steps

1. Review recent changes.
2. Update `/project/current-focus.md`.
3. Update `/project/backlog.md` statuses.
4. Add decision records if architecture changed.
5. Add or update risks.
6. Update release log.
7. Identify next 3 actions.

## Output

```md
## Updated Files

## Backlog Changes

## Decisions Added

## Risks Added/Updated

## Release Notes

## Next 3 Actions
```
