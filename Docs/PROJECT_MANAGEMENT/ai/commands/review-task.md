# Command: Review Task

Review completed work before merge.

## Steps

1. Compare changes to acceptance criteria.
2. Check for unrelated changes.
3. Check architecture impact.
4. Check risk impact.
5. Check docs updates.
6. Check tests/validation.
7. Check release notes impact.

## Output

```md
## Review Result

Pass / Needs Changes

## Acceptance Criteria

## Issues Found

## Required Fixes

## Suggested Improvements

## ProjectOS Updates Needed
```

## Rules

- Be direct.
- Do not pass incomplete work.
- Separate blockers from optional improvements.
