# Command: Plan Feature

Plan a feature without writing code.

## Steps

1. Read project files:
   - `/project/brief.md`
   - `/project/roadmap.md`
   - `/project/current-focus.md`
   - `/project/backlog.md`
   - `/project/decisions.md`
   - `/project/risks.md`
2. Confirm the roadmap phase.
3. Confirm or create a backlog item.
4. Define acceptance criteria.
5. Identify implementation steps.
6. Identify files likely to change.
7. Identify risks.
8. Identify tests/checks.
9. Stop before coding.

## Output

```md
## Roadmap Link

## Backlog Item

## Goal

## Assumptions

## Implementation Plan

## Files Likely to Change

## Risks

## Acceptance Criteria

## Review Plan
```
