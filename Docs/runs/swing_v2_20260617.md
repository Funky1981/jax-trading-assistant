# Swing V2 Implementation Run - 2026-06-17

## Scope

Implemented Swing V2 as a separate ETF swing trading option with paper-only, approval-gated candidate metadata, deterministic swing research gating, daily revalidation decision logic, and frontend visibility.

Non-swing readiness plans were treated as archived/completed and were not edited.

## Implemented

- Added `etf_swing_research` and `etf_swing_paper` to the trading modes catalog.
- Added explicit horizon policy types and validation for research-only, intraday, and swing horizons.
- Persisted Swing candidate horizon metadata in existing `candidate_trades.metadata` JSONB:
  - `horizonPolicy.horizon = "swing"`
  - `maxHoldDays <= 10`
  - `requiresDailyReview = true`
  - `paperOnly = true`
  - `approvalRequired = true`
- Kept World Monitor promotion approval-gated and confirmed it creates no execution instruction before approval.
- Added `internal/modules/swingresearch` deterministic thesis boundary.
- Added daily revalidation decision logic that can mark review-required or blocked and never creates broker instructions.
- Added frontend Swing Trading route/navigation and trading mode copy.
