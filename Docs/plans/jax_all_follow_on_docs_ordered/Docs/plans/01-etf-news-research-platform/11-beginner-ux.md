# 11 — Beginner UX

## Rule

If Jax cannot explain a candidate simply, it should not ask for approval.

## Required Screens

```text
ETF Universe
Strategy Cards
Candidate Trade Screen
Research Timeline
Simple / Detailed / Technical toggle
```

## Candidate Screen Must Show

```text
plain-English summary
ETF selected
why this ETF
news sources
price chart before/after news
priced-in verdict
other news/confounders
risk controls
entry/stop/target
approve/reject buttons
```

## Acceptance Criteria

- Beginner can understand what Jax is suggesting.
- User can see why Jax walked away.
- Strategy can be disabled.
