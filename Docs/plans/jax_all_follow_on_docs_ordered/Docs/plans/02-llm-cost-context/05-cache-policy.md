# 05 — Cache Policy

Cache allowed:

```text
docs Q&A
beginner explanations
strategy explanations
historical research summaries
event-study explanations
post-trade education text
```

Do not cache:

```text
current market state
current trade decision
approval summary
stop-loss/take-profit calculation
broker/order/position status
provider health
```

Start with exact cache. Add semantic cache later only for docs/history.
