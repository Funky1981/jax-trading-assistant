# Jax Backtest Evidence Skill

A backtest is not proof unless it includes:

- hypothesis
- setup family
- dataset id
- dataset hash
- date range
- benchmark
- assumptions
- slippage model
- fees model
- in-sample period
- out-of-sample period
- sample size
- drawdown
- expectancy
- failure modes

No strategy becomes PAPER_READY without evidence.

No strategy becomes LIVE_READY in the current roadmap.
