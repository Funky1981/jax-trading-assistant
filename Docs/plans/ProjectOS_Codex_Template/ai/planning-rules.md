# Planning Rules

Use these rules before implementing work.

## Required Checks

- Is this work linked to the roadmap?
- Is this work in the backlog?
- Is the current phase correct?
- Are the requirements clear?
- Are there architecture implications?
- Are there security, data, cost, or operational risks?
- Can the task be split smaller?

## Plan Output Format

```md
## Roadmap Link

## Backlog Item

## Goal

## Assumptions

## Implementation Steps

## Files Likely to Change

## Risks

## Acceptance Criteria

## Review Plan
```

## Rule

Planning is not implementation. Do not edit code during the planning step.
