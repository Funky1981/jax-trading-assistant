# Release Checklist

Use before tagging, deploying, or calling a milestone complete.

## Scope

- [ ] Release contents are clear
- [ ] Completed backlog items listed
- [ ] Deferred items documented
- [ ] Known issues documented

## Quality

- [ ] Tests/checks completed
- [ ] Critical bugs resolved or accepted
- [ ] Security risks reviewed
- [ ] Performance risks reviewed

## Documentation

- [ ] README updated
- [ ] Release log updated
- [ ] Operational notes updated
- [ ] Setup instructions still valid

## Deployment

- [ ] Config/secrets checked
- [ ] Database migrations reviewed
- [ ] Rollback considered
- [ ] Monitoring/logging checked

## Final Summary

```md
## Release Name

## What Changed

## Known Issues

## Deployment Notes

## Follow-up Work
```
