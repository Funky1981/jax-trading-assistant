# Command: Implement Task

Implement a planned task.

## Preconditions

The task must have:

- Roadmap link
- Backlog item
- Acceptance criteria
- Implementation plan

## Steps

1. Read the plan.
2. Confirm scope.
3. Implement only the planned changes.
4. Add/update tests where practical.
5. Run available checks.
6. Update ProjectOS files.
7. Summarise changes.

## Required Final Output

```md
## Implemented

## Files Changed

## Tests / Checks

## ProjectOS Updates

## Risks / Follow-ups
```

## Rules

- No unrelated rewrites.
- No silent architecture changes.
- No untracked TODOs.
