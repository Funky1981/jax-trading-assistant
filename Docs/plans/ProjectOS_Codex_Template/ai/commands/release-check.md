# Command: Release Check

Assess whether the project or milestone is ready to release.

## Steps

1. Review completed backlog items.
2. Review open risks.
3. Review known bugs.
4. Review tests/checks.
5. Review deployment/config changes.
6. Review docs.
7. Update `/project/releases.md`.

## Output

```md
## Release Readiness

Ready / Not Ready

## Completed Scope

## Blockers

## Known Issues

## Deployment Notes

## Follow-up Work
```

## Rule

Do not say ready unless the evidence supports it.
