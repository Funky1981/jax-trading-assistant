# Command: Create Roadmap

Create or refresh the project roadmap.

## Steps

1. Read `/project/brief.md`.
2. Inspect the current repo if available.
3. Identify the project vision.
4. Identify the current phase.
5. Break the work into phases:
   - Discovery / Baseline
   - Foundation
   - Useful MVP
   - Production Hardening
   - Expansion
6. Move speculative ideas into Parking Lot.
7. Output an updated `/project/roadmap.md`.

## Rules

- Keep the roadmap realistic.
- Do not include fantasy features in early phases.
- Put stability before advanced automation.
- Make each phase shippable.
