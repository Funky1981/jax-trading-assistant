# Implementation Rules

## Before Coding

Confirm:

- Roadmap phase
- Backlog item
- Acceptance criteria
- Risks
- Files likely to change

## While Coding

- Keep changes focused.
- Avoid unrelated refactors.
- Preserve existing behaviour unless the task explicitly changes it.
- Add tests where practical.
- Use clear names.
- Keep configuration explicit.
- Do not hide failures.

## After Coding

Update relevant files:

- `/project/current-focus.md`
- `/project/backlog.md`
- `/project/decisions.md`
- `/project/risks.md`
- `/project/releases.md`

## Completion Summary

Always include:

```md
## Changed

## Tests / Checks

## Docs Updated

## Risks / Follow-ups
```
