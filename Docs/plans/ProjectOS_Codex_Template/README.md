# ProjectOS Template

A reusable project operating system for new and existing software projects.

Use this template to enforce:

- Roadmaps
- Backlogs
- Current focus
- Architecture decisions
- Risk tracking
- Release notes
- Codex operating rules
- GitHub issue templates
- Pull request review discipline

## Recommended usage

Copy the contents of this template into the root of any project repo.

For existing projects, start with:

```text
/ai/commands/baseline-existing-project.md
```

For new projects, start with:

```text
/project/brief.md
/project/roadmap.md
```

## Core rule

No implementation work starts unless it is connected to:

1. The project brief
2. The roadmap
3. The backlog
4. A planned task
5. A review checklist

This system is intentionally lightweight, repo-local, and AI-friendly.
