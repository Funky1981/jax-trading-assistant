### DEC-001 — Use ProjectOS for project governance

**Date:** YYYY-MM-DD  
**Status:** Accepted  
**Owner:** TBC  

#### Context

The project needs a repeatable roadmap, backlog, delivery, review, and documentation process.

#### Options Considered

1. No formal process
2. External project-management tool only
3. Repo-local ProjectOS plus GitHub issues/projects

#### Decision

#### Consequences

Project state remains close to the code and accessible to AI assistants. The process requires discipline to keep files updated.
