# Backlog

## Rules

Every backlog item must have:

- Clear outcome
- Roadmap link
- Priority
- Status
- Acceptance criteria
- Risk notes if relevant

## Status Values

- Proposed
- Accepted
- Planned
- In Progress
- Review
- Done
- Released
- Rejected

## Priority Values

- P0 — Critical
- P1 — Important
- P2 — Useful
- P3 — Later
