# GitHub Project Board Setup

Create one GitHub Project per serious project.

## Recommended Views

### Board View

Columns:

1. Proposed
2. Accepted
3. Planned
4. In Progress
5. Review
6. Blocked
7. Done
8. Released

### Roadmap View

Group by roadmap phase.

### Risk View

Filter by label:

```text
label:risk
```

### Release View

Group by milestone.

## Recommended Fields

- Status
- Priority
- Roadmap Phase
- Type
- Risk Level
- Target Release
- Owner

## Labels

Create these labels:

```text
feature
bug
tech-debt
architecture
decision
risk
documentation
release
blocked
P0
P1
P2
P3
```

## Rule

GitHub issues track execution. `/project` files track truth and context.
