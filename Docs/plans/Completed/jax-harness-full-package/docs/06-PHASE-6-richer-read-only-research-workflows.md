# Phase 6 - Richer Read-Only Research Workflows

Goal:
Increase research freedom safely.

Good expansions:
- cross-run comparison
- strategy-instance summaries
- blocked-candidate analysis
- recent research run narrative
- confidence drift summary
- signal clustering overview
- artifact/replay summary for strategies

Bad expansions:
- direct broker interaction
- direct approval actions
- direct execution actions
- external news scraping without provenance
- pretending to know live market conditions without a trusted feed

Rule:
Research can be broad.
Trading actions must remain narrow and deterministic.

Acceptance:
- Users can ask deeper research questions
- Assistant still refuses unsupported conclusions
- No mutation path is added
