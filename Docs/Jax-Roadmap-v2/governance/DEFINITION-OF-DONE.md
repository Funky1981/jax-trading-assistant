# Programme Definition of Done

A feature is not considered complete merely because code exists.

At package level, Done means:
- acceptance criteria pass,
- tests cover success and relevant failure paths,
- source/provenance/versioning requirements are met,
- operational failure is observable,
- safety invariants are preserved,
- documentation/contracts are updated,
- reviewer returns GO or accepted CONDITIONAL GO.

At programme level, Jax is considered successfully useful before live trading if it can:
1. ingest trustworthy market/corporate/macro/event evidence;
2. resolve affected instruments correctly;
3. calculate deterministic quantitative context;
4. produce explainable, evidence-linked recommendations;
5. replay/evaluate those recommendations historically and prospectively;
6. account for portfolio state and deterministic risk;
7. operate a high-fidelity paper workflow under human approval.
