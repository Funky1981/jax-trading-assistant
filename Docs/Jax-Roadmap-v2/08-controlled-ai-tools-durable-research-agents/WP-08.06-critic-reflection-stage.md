## Internal implementation evidence

- Added versioned critic policy and critique contracts with a hard maximum of
  three cycles and bounded finding/report/gap sizes.
- Findings explicitly classify unsupported claims, omissions, contradictions,
  stale evidence, weak source independence, unknowns, overconfidence,
  counter-case gaps and recommendation implications. Every finding and
  requested gap must reference evidence already present in the task state.
- Applying a critique can downgrade a report, add explicit unknowns, retain
  contradictions and request bounded research. It cannot change the objective,
  plan, tools, permissions, budgets or execution authority; existing
  contradictions are required to survive reflection.
- Critique input is content-addressed to the current report, preventing stale
  or replayed reflection from being applied. Injection-shaped content remains
  data and the output contract is execution-disabled.
