## Internal implementation evidence

- Added the versioned `jax.research_replan/v1` contract for evidence-linked
  gaps, bounded plan steps, immutable original objectives, plan-version
  changes, reasons, trigger evidence, outcomes and replan sequence numbers.
- Replanning is restricted to registered, version-matched, permitted read-only
  tools. It rejects unknown/forbidden tools, missing task evidence, duplicate
  steps, objective mutation, stale plan sequence and policy/candidate bounds.
- Explicit bounded outcomes include research sufficient, insufficient evidence,
  blocked and budget exhausted. Applying an approved plan changes only the
  research plan/checkpoint metadata; it does not change budgets, permissions,
  recommendations or execution state.
- Replan count is persisted in the Phase-08 checkpoint state and bounded by the
  checkpoint/replan policies. Tool-output-shaped instructions remain ordinary
  evidence and cannot redefine the objective.
- Verification: `go test ./internal/modules/harness` and `git diff --check`.
