## Internal implementation evidence

- Added the versioned `jax.research_checkpoint/v1` contract. A checkpoint
  carries task identity, objective, plan version, completed step evidence,
  unresolved gaps, contradictions, report state, controlled-tool records,
  model/prompt/usage provenance, budget state, status and failure state.
- Added immutable content-addressed checkpoint identities and both in-memory
  and Postgres-backed stores. The additive migration persists structured JSONB
  state independently of chat transcripts and prevents task/version mutation.
- Resume reconstruction emits only bounded minimum sufficient context: the
  objective, current plan, completed/evidence identities, gaps, contradictions,
  report and remaining budget/steps. It does not replay a historical
  transcript. Corrupt, oversized, incompatible or over-budget state fails
  closed.
- Adversarial integrity checks reject duplicate or out-of-plan completed steps,
  malformed/trusted tool records, invalid evidence and tampered budget state.
- Verification: `go test ./internal/modules/harness ./db/postgres/migrations`
  and `git diff --check`.
