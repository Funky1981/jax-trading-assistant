# Phase 06 Reference Notes — Research & Recommendations

## Fincept lessons
The useful parts are structured data/tool access and research composition, not investor personas.

## Jax target
Create an evidence packet that separates:
- observed facts,
- deterministic quant results,
- model-generated interpretation,
- supporting evidence,
- counter-evidence,
- unknowns/missing evidence,
- freshness/quality,
- time horizon,
- invalidation conditions.

Recommendation eligibility is deterministic: insufficient/stale evidence must prevent candidate promotion even if an LLM is confident.

## UI rule
This is the first phase where substantial recommendation UI becomes worthwhile. UI should expose evidence and uncertainty, not merely a BUY/SELL badge.
