## Internal implementation evidence

- Volatility uses natural-log close-to-close returns, an explicit recent-return
  window, sample standard deviation (`n-1`), and caller-supplied annualization.
- ATR uses simple average of explicit true ranges
  `max(high-low, abs(high-prevClose), abs(low-prevClose))`; the first bar has no
  prior-close range and is excluded.
- Drawdown uses `close/running_peak - 1`, exposing current and most-negative
  maximum drawdown as separate finite values.
- Verification: `go test ./internal/modules/quant -run 'Volatility|ATR|Drawdown' -count=1`.
- Adversarial review covered insufficient history, invalid windows, zero/NaN
  results, prior-close boundaries, annualization, running peaks, and hand-
  calculated true ranges.
