# WP-11.05 implementation evidence

Status: `IMPLEMENTED / INTERNALLY VERIFIED`

`PaperLedger` is a separate paper-account domain. Immutable paper fill events
derive cash, positions, average cost, fees, realised P&L and equity; callers
cannot directly edit balance state. BUY fills reduce cash and create/increase
long positions. SELL fills require an existing long position and increase cash,
realised P&L and fees. Opening shorts, negative cash, over-capital fills and
unknown mark prices fail closed. Duplicate fills are idempotent and cannot
create a second ledger event.

Verification:

- `go test ./internal/modules/papertrading -count=1` — PASS.
- Covered cash/position/average-cost arithmetic, fees, realised P&L, duplicate
  fills, insufficient capital, first-sale/short denial and missing mark price.

The paper account is never written to the Phase-09 observed portfolio or any
real broker/account state.
