# Phase 13 Reference Notes — Optional Live

## Fincept concepts
Broker capability abstraction, session validation, explicit live gating, kill paths and reconciliation are useful reference patterns.

## Jax target
Live is a narrow adapter boundary around an already-proven paper workflow. It must not cause research/AI components to gain broker credentials or direct execution authority.

The live phase does not start merely because it exists in the roadmap. It requires sustained paper evidence and a fresh explicit user decision.
