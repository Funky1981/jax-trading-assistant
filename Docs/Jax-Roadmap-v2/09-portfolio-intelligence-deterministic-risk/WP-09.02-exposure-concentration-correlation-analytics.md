# Work Package 09.02 — Exposure/concentration/correlation analytics

## Objective
Deliver **Exposure/concentration/correlation analytics** as the next smallest independently reviewable increment of Phase 09.

## Implementation evidence

- Status: implemented and internally verified; WP-09.03 current.
- `internal/modules/portfoliorisk/analytics.go` consumes the canonical
  snapshot and reuses Phase-05's signed quantity semantics: positive values are
  long, negative values are short, gross is the sum of absolute signed market
  values, and net preserves signs.
- Analytics are content-identified by snapshot identity, algorithm version,
  valuation basis, parameters and provenance. Instrument concentration uses
  absolute market value divided by known positive equity; unknown equity,
  valuation, instrument resolution or freshness fails closed.
- Correlation requires strictly increasing UTC aligned observations, a minimum
  three-sample window, no observations after the valuation anchor, fresh data,
  finite values and non-zero variance. It returns explicit
  `UNKNOWN / INSUFFICIENT_DATA` rather than a confident diversification claim.
- No sector/industry/geography classification is invented and no external data
  service is added.
- Verification: `go test ./internal/modules/portfoliorisk -count=1`.
