# Work Package 09.04 — Deterministic recommendation risk checks

## Objective
Deliver **Deterministic recommendation risk checks** as the next smallest independently reviewable increment of Phase 09.

## Implementation evidence

- Status: implemented and internally verified; WP-09.05 current.
- `EvaluateRecommendation` is a pure deterministic evaluator over a Phase-06
  recommendation input, canonical snapshot, Phase-09 analytics and versioned
  policy. It returns exactly `ACCEPT`, `AMEND` or `REJECT` with stable reason
  codes and a content-derived decision identity.
- Unknown/stale portfolio facts, invalid policy, currency mismatch, invalid
  recommendation inputs, leverage above 1x, missing risk allocation and
  non-`NONE` execution authority fail closed. Model confidence is provenance
  only and cannot override a failed risk rule.
- AMEND is bounded by remaining position/concentration/gross/net/cash capacity;
  REJECT is a normal result when no capacity or a hard safety condition exists.
  The evaluator creates no approval, order, trade, fill or portfolio mutation.
- Verification: `go test ./internal/modules/portfoliorisk -count=1`.
